# 焙日 Bairi 設計規範

前台的視覺依據。實作 Blade 頁面與 Vue 元件時，顏色、字體、間距一律從這裡取，不要每頁各自發明。

`mockups/` 裡是定案設計稿的原始碼：桌機版四頁（`Main` 首頁、`List` 商品列表、`Product` 咖啡豆詳情、`Cart` 購物車），以及手機版四頁（檔名加 `Phone`，寬 390px）。它們是 Claude 設計畫布的格式（`.dc.html`），不能直接在瀏覽器開啟，但 HTML 結構與 inline style 可以直接當作實作參考。範例中的咖啡豆名稱、價格與風味描述可以沿用為種子資料。

## 風格

日系極簡：米白底、大量留白、細線分隔、放寬字距、只用一個強調色。商品圖片使用牛皮紙袋插圖（CSS 繪製或 SVG），不使用實拍照片。點綴性的直書小字（`writing-mode: vertical-rl`）用在大圖旁。

不要用：漸層、陰影卡片（商品袋子本身的柔和陰影除外）、圓角大按鈕、emoji、多種強調色。

| 用途 | 色碼 |

| 主文字、主按鈕底色 | `#26221D` |

| 分隔線 | `#DDD5C8` |
| 外框（按鈕、標籤、數量選擇器） | `#C9BFB0` |

所有文字在對應背景上的對比度至少 4.5:1。

## 字體

Google Fonts：Noto Serif TC（400/500/600）、Noto Sans TC（400/500）、Cormorant Garamond（400/500）。

| 用途 | 字體 | 大小 | 字距 |
| --- | --- | --- | --- |

| 區塊標題 | Noto Serif TC 500 | 26–32px | 0.1em |

## 版面與間距

- 內容最大寬度 1200px，左右留白 `clamp(16px, 4vw, 48px)`。
- 區塊之間上下留白 96px，區塊之間用 1px `#DDD5C8` 分隔線。
- 商品卡片格線：`repeat(auto-fill, minmax(240px, 1fr))`，間距 48px（列）／32px（欄）。
- 兩欄版面（詳情頁、購物車）用 `flex-wrap`，手機寬度自動變成單欄。
- 所有可點擊元素至少 44×44px。
- 斷點：960px 以下商品卡片列改為一次兩張；手機版（約 600px 以下）採用下方「手機版」的版面規則。

## 元件

- **主按鈕**：底色 `#26221D`、文字 `#F5F1EA`、直角、高 52–56px、字距 0.14–0.16em。
- **次要連結按鈕**：無底色，下方 1px 實線。
- **選項按鈕（規格、研磨方式）**：未選 1px `#C9BFB0` 外框；已選規格為深色底反白，已選研磨為深色雙線外框；已售完為虛線外框、刪除線、不可點。
- **數量選擇器**：1px `#C9BFB0` 外框，− 數字 ＋ 三格。
- **風味標籤**：1px `#C9BFB0` 外框、全圓角、13px。
- **資訊三格**：1px `#DDD5C8` 格線分隔的三欄（產地／處理法／烘焙度）；烘焙度用 5 段短橫條表示。
- **購買區／訂單摘要**：`#FBF9F5` 底、1px `#DDD5C8` 外框，與頁面其他內容區隔。
- **步驟編號**：Cormorant 強調色的 `01`、`02` 加在欄位標題前。
- **免運進度**：`#ECE6DC` 底的提示框，內含 3px 高的強調色進度條。
- **demo 提示列**：每頁最上方，`#26221D` 底、12px 字，說明資料會自動重置與綠界測試卡號（卡號實作前須對照綠界文件確認）。

- **橫向卡片列**（首頁「本週烘焙」）：桌機一次顯示四張，標題列右側有左右圓形箭頭（44px、細線外框，hover 轉深色底），每次捲動一張；隱藏原生捲軸，觸控板可直接滑，並以 scroll-snap 對齊卡片、`scroll-padding` 對齊內容左緣。手機版不顯示箭頭，只用手指滑，右側露出半張卡片提示可滑。
- **推薦摺疊**（詳情頁「你可能也喜歡」）：預設顯示一排四張，標題右側顯示總數；超過四張時下方出現兩側帶細線的「查看更多（N 支）」按鈕，展開後變「收合」。不足四張時不顯示按鈕。
- **篩選欄**（列表頁桌機）：左側欄，風味／產地／處理法／烘焙度四組勾選框，可複選，選項旁標數量；同組為「或」、不同組為「且」。已選條件以深色圓角標籤列在結果上方，可單獨移除或「清除全部」；搜尋比對名稱與風味描述；排序為最新上架、價格低到高、價格高到低；無結果時顯示空狀態與「清除所有篩選」。

## 手機版

- **頁首**：左選單按鈕、中 Logo、右購物車（含數量）；內頁左側改為返回箭頭。demo 提示列縮成一行 11px。
- **抽屜選單**：從左滑出、寬 84%，右側半透明遮罩點擊即關閉；內含搜尋框、主選單（大字襯線＋英文小標）、底部會員與購物車連結。
- **篩選面板**：由「篩選（已選數）」按鈕開啟，從底部滑出、上緣 16px 圓角；選項改為圓角膠囊按鈕；底部固定「查看 N 支咖啡豆」按鈕即時顯示結果數；右上有「清除全部」與關閉。
- **詳情頁底部固定列**：價格（依數量計算）＋已選規格・研磨・數量（低庫存時附剩餘包數）＋「加入購物車」，任何捲動位置都按得到；加入後在固定列上方出現深色提示與「查看」連結。購買區步驟為 01 規格、02 研磨方式、03 數量。
- **購物車底部固定列**：總計（標示含運費或免運）＋「前往結帳」。
- 商品列表為兩欄卡片。

## 頁面重點

- **首頁**：主視覺（標語＋大張紙袋插圖）→ 從風味開始找（四格）→ 本週烘焙（橫向卡片列）→ 三個承諾（小批次烘焙、下單後才研磨、滿額免運）→ 頁尾。
- **商品列表**：標題與結果數 → 左篩選欄、右搜尋排序列＋已選標籤＋商品卡片格線 → 分頁。
- **咖啡豆詳情**：左大圖；右側依序為商品介紹、資訊三格、購買區（價格與庫存 → 01 規格 → 02 研磨方式 → 數量與加入購物車）、運送說明；下方「你可能也喜歡」（可摺疊）。
- **購物車**：訪客提示 → 免運進度 → 購物車項目列表 → 右側訂單摘要；空購物車有獨立的引導畫面。
