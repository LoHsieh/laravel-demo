# 焙日 Bairi 設計規範

前台的視覺依據。實作 Blade 頁面與 Vue 元件時，顏色、字體、間距一律從這裡取，不要每頁各自發明。

`mockups/` 裡是三頁定案設計稿的原始碼（首頁、咖啡豆詳情、購物車）。它們是 Claude 設計畫布的格式（`.dc.html`），不能直接在瀏覽器開啟，但 HTML 結構與 inline style 可以直接當作實作參考。範例中的咖啡豆名稱、價格與風味描述可以沿用為種子資料。

## 風格

日系極簡：米白底、大量留白、細線分隔、放寬字距、只用一個強調色。商品圖片使用牛皮紙袋插圖（CSS 繪製或 SVG），不使用實拍照片。點綴性的直書小字（`writing-mode: vertical-rl`）用在大圖旁。

不要用：漸層、陰影卡片（商品袋子本身的柔和陰影除外）、圓角大按鈕、emoji、多種強調色。

所有文字在對應背景上的對比度至少 4.5:1。

## 版面與間距

- 內容最大寬度 1200px，左右留白 `clamp(16px, 4vw, 48px)`。
- 區塊之間上下留白 96px，區塊之間用 1px `#DDD5C8` 分隔線。
- 商品卡片格線：`repeat(auto-fill, minmax(240px, 1fr))`，間距 48px（列）／32px（欄）。
- 兩欄版面（詳情頁、購物車）用 `flex-wrap`，手機寬度自動變成單欄。
- 所有可點擊元素至少 44×44px。

## 元件

- **主按鈕**：底色 `#26221D`、文字 `#F5F1EA`、直角、高 52–56px、字距 0.14–0.16em。
- **次要連結按鈕**：無底色，下方 1px 實線。
- **選項按鈕（規格、研磨方式）**：未選 1px `#C9BFB0` 外框；已選規格為深色底反白，已選研磨為深色雙線外框；已售完為虛線外框、刪除線、不可點。
- **數量選擇器**：1px `#C9BFB0` 外框，− 數字 ＋ 三格。
- **風味標籤**：1px `#C9BFB0` 外框、全圓角、13px。
- **資訊三格**：1px `#DDD5C8` 格線分隔的三欄（產地／處理法／烘焙度）；烘焙度用 5 段短橫條表示。
- **購買區／訂單摘要**：`#FBF9F5` 底、1px `#DDD5C8` 外框，與頁面其他內容區隔。
- **步驟編號**：Cormorant 強調色的 `01`、`02` 加在欄位標題前。
- **免運進度**：`#ECE6DC` 底的提示框，內含 3px 高的強調色進度條。
- **demo 提示列**：每頁最上方，`#26221D` 底、12px 字，說明資料會自動重置與綠界測試卡號（卡號實作前須對照綠界文件確認）。

## 頁面重點

- **首頁**：主視覺（標語＋大張紙袋插圖）→ 從風味開始找（四格）→ 本週烘焙（商品卡片）→ 三個承諾（小批次烘焙、下單後才研磨、滿額免運）→ 頁尾。
- **咖啡豆詳情**：左大圖；右側依序為商品介紹、資訊三格、購買區（價格與庫存 → 01 規格 → 02 研磨方式 → 數量與加入購物車）、運送說明；下方「你可能也喜歡」。
- **購物車**：訪客提示 → 免運進度 → 購物車項目列表 → 右側訂單摘要；空購物車有獨立的引導畫面。
