# 每次從休眠醒來時重置 demo 資料

網站公開提供店家測試帳號，讓面試官能實際操作後台，因此資料需要定期回到種子資料。我們選擇在容器啟動時重置，而不是在固定時間用排程重置：Render 免費方案閒置 15 分鐘就休眠，固定時間的排程幾乎不會執行，Laravel 也不會補跑錯過的任務；而容器啟動代表前 15 分鐘沒有人在使用，重置不會打斷任何人的操作。

## Considered Options

- **每日固定時間重置**：休眠時不會執行，且可能打斷正在操作的人。
- **店家測試帳號唯讀**：資料不會亂，但面試官無法實際體驗後台的新增、修改與圖片上傳。

## Consequences

- 這是刻意的設計：重啟後資料消失不是錯誤，不要把它當成 bug 修掉。此行為只在 demo 環境啟用，由環境變數控制。
- 種子資料的商品圖片固定存放在圖片服務上，重置時只寫入網址，不重新上傳。
- 冷啟動會多花幾秒重建資料。
- 頁面上方顯示提示，說明 demo 資料會在閒置後自動重置。
