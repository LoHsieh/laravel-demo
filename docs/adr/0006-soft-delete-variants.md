# 規格以軟刪除，咖啡豆只能下架

訂單項目以外鍵指向規格，資料庫會拒絕刪除已有訂單的規格；若改成連帶刪除，訂單會失去品名與重量，金額也對不上。因此店家刪除規格時只做軟刪除（`deleted_at`），咖啡豆不提供刪除，只能下架。已刪除的規格不出現在前台、不能加入購物車或結帳，但既有訂單仍能顯示它。

## Considered Options

- **硬刪除，遇到外鍵錯誤時拒絕**：沒有訂單的規格可以真正刪掉，但店家無法刪除賣過的規格，只能留著它繼續出現在前台。
- **訂單項目保存品名與重量的快照，規格可以硬刪除**：訂單完全不依賴規格，但要多存一份資料，且歸還庫存保留仍需要規格存在。

## Consequences

- 「可購買的規格」除了咖啡豆上架，還必須尚未刪除；購物車中的已刪除規格要像已下架一樣處理。
- 讀取訂單項目的規格時要包含已刪除的規格（`withTrashed`）。取消訂單歸還庫存保留時也一樣，否則軟刪除的全域範圍會讓歸還靜默地不生效。
- 外鍵仍保留，是最後一道防線：萬一有程式硬刪除，資料庫會拒絕。後台捕捉這個錯誤（MySQL 1451），顯示「此規格已有訂單，無法刪除」，不顯示 500。
